    [orchestration]

    What Mastra does

    Mastra is a TypeScript framework for coordinating language models with an application's instructions, tools, data and workflows. Your product owns its interface and business rules. Mastra supplies the orchestration layer; model providers and other services supply the infrastructure. An agent framework does not replace the model or guarantee that an answer is correct.

    [agent]

    The agent and its loop

    An agent combines a model, instructions and available tools, with memory when configured. The model can request a tool, inspect its result and continue toward an answer. Give the run explicit limits. generate() returns a completed generation result; stream() supports incremental output. This example uses generate() and sends application events to the browser while work happens.

    [tools]

    Tools give the agent an action

    A tool has an identifier, a description, an input schema and an implementation. Its schema validates values at the application boundary. Our searchLessonDocs tool performs keyword search over these six bundled lesson notes and returns source IDs with the passages. The tutor must cite returned source IDs. This is a small document-search example; it does not use embeddings or a vector database.

    [workflows]

    When a workflow helps

    A workflow expresses a defined sequence or branch. A support process might fetch customer data, classify a ticket, then draft a reply or pause for a human decision. An agent decides its next action within its instructions and available tools. This introductory app runs an agent; the support workflow is a conceptual example, not an implemented feature of this app.

    [context]

    Memory and retrieval

    Memory can provide conversation history, selected working facts or relevant older messages when storage is configured. Retrieval supplies relevant source passages as evidence. A larger retrieval pipeline can chunk documents, embed them and query a vector store. This app uses local keyword retrieval and starts each tutor run without persisted conversation memory. Grounding still needs instructions and citation checks.

    [observability]

    Inspect and verify the result

    Tracing records model calls, tool calls and workflow steps when configured. Logs expose events; evaluations assess properties such as relevance and evidence use. This app displays a small application event log, actual search results and checks on cited source IDs. It does not configure a telemetry backend or an evaluation platform. Provider choice, storage, authorization and operational checks remain application responsibilities.
