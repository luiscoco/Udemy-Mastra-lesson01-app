01

Install and start

Use Node.js 24 or newer and npm. The committed lockfile fixes the dependency versions. Starting the server does not call a model.

Clone and start the completed application

git clone https://github.com/luiscoco/Udemy-Mastra-lesson01-app.git
cd Udemy-Mastra-lesson01-app
npm ci
npm start

Open http://127.0.0.1:3201. Keep the terminal open. Press Ctrl+C to stop the server.

Choose Try document search in the application lab. This works immediately and returns real passages without a provider key.

02

Configure the live tutor

Stop the server first. Copy the example only if you do not already have a local configuration file.

PowerShell: create your local configuration

if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env

Replace the placeholder in your own .env file

OPENAI_API_KEY=your_api_key
MASTRA_MODEL=openai/gpt-4.1-mini
PORT=3201

Use a model your provider account can access. The app accepts an openai/model-name identifier. Your key stays on the server and is never sent to the browser.

Restart after changing the environment

npm start

A key already set in the launching shell takes precedence over the optional .env file. Another terminal does not inherit an environment variable set later in the first terminal.

Bash / macOS / Linux alternative

Bash setup

[ -f .env ] || cp .env.example .env
# Edit .env with your preferred editor.
npm start
03

Run and inspect

  1. Ask: How does Mastra connect an agent with tools and data?
  2. Choose Run tutor agent. This calls your provider and may incur API usage.
  3. Inspect the search event, returned passages, final answer and cited IDs.
  4. Confirm that the answer's claims are supported by the passages, beyond the automatic ID check.
  5. Try Stop during a run. The server requests cancellation. Each run also has a 90-second deadline and at most three model steps.

The answer is generated with generate() and displayed when ready. Application events arrive while the run is active.

Terminal samples

Search needs no key; sample calls the real tutor

npm run search -- "memory and retrieval"
npm run sample -- "What is an agent?"

The sample command loads an optional local .env file. It uses the same agent, tool and checks as the browser application.

Build and verify your changes

Regenerate pages and browser code, then run the offline checks

npm run build
npm test

The code walkthrough excerpts are generated from the actual TypeScript files. Rebuild after editing source so the pages and line references stay current. The tests do not call a paid model.

Installed Mastra version: 1.81.0. This complete project includes both source files and the generated public pages.

Troubleshooting

What you seeWhat to check
Provider key neededReplace the placeholder in .env, then restart the same server process. You can still try local search.
Provider could not finishCheck credentials, model access, provider credit and network access. The UI intentionally does not display raw provider exceptions.
Needs reviewThe generation did not finish with valid returned-source citations. Read the evidence, try a supported lesson question, or inspect the run limit.
No matching passagesAsk about a lesson topic. The search is limited to the six bundled notes.
Port is in useStop the existing server or set a different PORT in .env. Use the URL printed in the terminal.
